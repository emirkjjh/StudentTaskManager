# Список найденных ошибок и предложений
 
**Проект:** Менеджер задач для студентов  
**Версия приложения:** 1.0  
**Дата:** 28.11.2025  
**Автор:** Эмир
 
## Ошибки
 
1. **Загрузка пустого JSON-файла**  
  - Описание: Если файл JSON пустой или повреждён, приложение выбрасывает исключение.  
  - Рекомендация: Добавить проверку на пустой или некорректный файл перед загрузкой.  
 
2. **Подтверждение удаления иногда не отображается**  
  - Описание: В редких случаях окно «Вы уверены?» появляется с задержкой.  
  - Рекомендация: Проверить порядок вызова окна Alert и синхронизацию событий.  
 
## Предложения по улучшению
 
1. **Добавить подсказки (Tooltips) к кнопкам и полям**  
  - Объяснение: Новые пользователи быстрее ориентируются в интерфейсе.  
 
2. **Улучшить визуальное оформление статистики**  
  - Объяснение: Графическое отображение количества задач и процента выполнения делает информацию нагляднее.  
 
3. **Добавить инструкцию по работе с JSON**  
  - Объяснение: Позволяет пользователям безопасно сохранять и загружать данные.  
 
4. **Цветовая схема кнопок и интерфейса**  
  - Объяснение: Сделать кнопки и вкладки более контрастными для удобства.
