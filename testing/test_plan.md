# План тестирования
 
**Проект:** Менеджер задач для студентов  
**Версия приложения:** 1.0  
**Дата:** 27.11.2025  
**Автор:** Эмир
 
## Цели тестирования
 
**Функциональное тестирование:**  
- Проверка операций добавления, редактирования и удаления задач (CRUD)  
- Проверка фильтров и поиска задач  
- Проверка сохранения и загрузки данных в формате JSON, txt  
- Проверка корректности работы вкладок приложения  
 
**Пользовательское тестирование:**  
- Проверка удобства интерфейса  
- Проверка понятности инструкций  
- Оценка логики отображения статистики задач  
 
## Инструменты тестирования
 
- **IDE:** IntelliJ IDEA  
- **Язык и фреймворк:** Java 17, JavaFX  
- **Библиотеки:** Gson для работы с JSON  
- **Дополнительно:** экран для демонстрации тестов, наблюдение за результатами  
 
## Среда тестирования
 
- **ОС:** Windows 10 / macOS / Linux  
- **Конфигурация ПК:** любой современный компьютер, поддерживающий Java 17  
- **Примечание:** для проверки сохранения/загрузки данных обязательно наличие прав на запись файлов  
 
## Ответственные
 
- **Эмир:** проведение функционального тестирования, документирование  
- **Одногруппники:** участие в пользовательском тестировании, обратная связь
