Менеджер задач для студентов
Описание проекта
JavaFX-приложение для управления учебными задачами студентов.
Позволяет создавать, редактировать, удалять и отслеживать выполнение задач. Подходит для студентов и преподавателей, чтобы планировать домашние задания, проекты и экзамены.

Основные функции:
• CRUD операции с задачами (создание, редактирование, удаление, просмотр)
• Фильтрация задач по названию
• Отдельное окно добавления задачи
• Мини-статистика: количество задач, процент выполненных
• Сохранение и загрузка данных в формате JSON
• Валидация полей и подтверждение удаления

Установка и запуск
1. Убедитесь, что у вас установлен Java JDK 17 или выше.
2. Скачайте или клонируйте репозиторий:
git clone https://github.com/ваш_ник/StudentTaskManager.git
3. Откройте проект в IntelliJ IDEA или другой IDE с поддержкой JavaFX.
4. Добавьте библиотеку JavaFX в зависимости проекта.
5. Запустите App.java как Java Application.
6. Приложение откроется, и вы сможете работать с задачами.

Примеры использования
• Создание задачи: нажмите кнопку «Добавить задачу», заполните поля и нажмите «Сохранить».
• Удаление задачи: выберите задачу в списке и нажмите «Удалить». Подтвердите действие.
• Фильтрация задач: введите текст в поле поиска — таблица автоматически отобразит соответствующие задачи.
• Просмотр статистики: перейдите на вкладку «Статистика» — будет показано количество задач и процент выполненных.
